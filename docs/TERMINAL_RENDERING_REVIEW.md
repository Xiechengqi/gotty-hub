# GoTTY / Hub 字体清晰度修复与整体 Review

核验日期：2026-11-11。GoTTY 基线 `b836fcb`，Hub 基线 `cf50e26`。本次修改两端字体渲染、Hub 预览、共享包和回归测试，保留现有分屏功能。

## 实现结果

旧版 GoTTY 声明 Source Code Pro，却没有随程序提供该字体，实际依赖设备字体回退；Hub 加载了真正的 Source Code Pro。原截图字格分别约为 8×16 和 8×18，笔画也不同。修复将两端无显式偏好时的默认主字体统一为内置 DejaVu Sans Mono、14px，普通/粗体为 400/700，行高系数 1、字间距 0。原截图的确切系统回退字体仍不能仅凭图片确定；所选方案通过随包字体消除这类不确定性。

## 发布与适用范围

- 已保存字体不会自动改成 DejaVu Sans Mono。需要采用新默认时，可在 Hub 点击“恢复默认”并保存；独立 GoTTY 可直接选择 DejaVu Sans Mono。
- 默认字体首次加载 505,336 字节，比原 Source Code Pro 的 164,576 字节增加约 333 KiB，后续复用浏览器缓存；整体字体资源目录未增加字体文件。
- 中文、emoji 等缺失字形继续依赖系统字体。验证环境为 Linux Chromium，不能据此承诺跨操作系统、Safari/Firefox 或不同 GPU 逐像素一致。
- 本次完成源码、内嵌资源和隔离构建验证，未替换 `/usr/local/bin/gotty` 或重启现有线上 PTY。上线需使用新二进制及配套前端资源；单独更新源码不会改变旧进程已内嵌的页面。
