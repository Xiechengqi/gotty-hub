| --- | --- |
| 菜单项目 | 保留“刷新”、分屏相关操作、有权限的“重启”和“删除”；删除所有菜单分割线 |

## 整体 Review

- 删除权限按实例所有者判断，独立于终端在线状态、输入权限及重启能力；后端仍严格校验所有者，操作者和观察者直接请求删除均返回 403。
- 复用 BoardUI `AlertDialog` 显示实例名及解除绑定的影响。取消不发请求；请求期间阻止重复提交；失败保留 tab、分屏及错误提示，允许重试。
- 删除成功后立即更新本地实例与工作区，再由 SSE 同步其他客户端。删除分屏成员后解除失效分组，保留另一侧 xterm、连接和焦点；删除最后一个实例后回到可添加实例的空工作区。
- 删除状态按账号隔离，异步结果返回时检查账号；确认框组件使用独立 key，避免与终端设置组件冲突。
- 清理实际前端逻辑及不再使用的状态转换，没有仅通过 CSS 隐藏旧入口。后台既有授权及设备协议保持兼容，避免影响已经授权的客户端。
