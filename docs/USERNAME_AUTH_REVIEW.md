# 用户名账号、固定 admin 与一步接入：实施结果及整体 Review

日期：2026-11-09。范围：GoTTY Hub 与 GoTTY 两个仓库的本地实现、构建、真实联调及整体 review。实施基线为 Hub `8848bf5`、GoTTY `9ab9247`。当前 Hub 版本为 `0.2.0`，对应 [实施规划](USERNAME_AUTH_PLAN.md)。

## 交付结果

- Hub 完全移除 Resend、邮箱账号、OTP、邮件重置、outbox、邮件任务及双阶段设备确认接口。公开注册与登录均使用用户名和密码，注册后直接建立会话。
- 管理员用户名固定为 `admin`。首次无参数启动必须隐藏输入一次非空密码，空白值重试；无用户名、邮箱或 API key 输入。首次监听前创建管理员，公开注册不能占用 admin 或注入管理员身份。
- 管理员原始密码按要求保存至 `~/.gotty-hub/config`，文件 `0600`、数据目录 `0700`。数据库、日志和升级文件默认也在此目录；数据库中的所有账号密码使用 Argon2id 哈希。
- 支持 `gotty-hub [serve] --password VALUE` 与 `--password-stdin`。优先级为 CLI > `HUB_PASSWORD` > config；已有配置时启动覆盖不改写 config，`config` / `configure` 显式保存。Web 修改 admin 密码同步保存 config；下次启动仍以启动覆盖值为准。
- 普通用户可修改密码、退出当前或全部会话。忘记密码改用服务器本机 `users reset-password --username USER`，同时撤销该用户旧会话，无外部恢复服务。
- GoTTY 表单只填写 Hub URL 和用户名，单次提交注册并连接；实例名自动生成，凭据只由后端私有保存。用户名不存在时给出明确提示及 Hub Web 注册链接，注册后可在原表单重试。
- GoTTY Hub 按钮改为原右上角控件相同的 28×28 SVG 图标样式；复用主站登录态，移除额外 `.admin` 管理令牌。所有分享入口均禁止读取或修改 Hub 管理配置，并隐藏入口。
- Hub 授权、偏好、会话和终端网关统一关联用户 ID，授权操作输入用户名。后台继续提供统计、升级/重启和日志，邮件统计改为离线实例数量。
- README、API/OpenAPI、管理员/运维说明、ADR、部署变量及测试夹具已同步更新。旧实施文档明确标记为历史记录。

## 整体 Review 结论

在本轮审阅及本地验证覆盖范围内，未发现尚未处理的阻断问题。重点检查了管理员初始化顺序、启动覆盖与持久化的一致性、公开路由鉴权边界、终端权限、设备凭据生命周期、保存失败后的恢复和前端资源嵌入。

Review 中已修正的边界：

1. **stdin 启动后重启**：exec 不能再次读取已耗尽的密码管道。重启移除 `--password-stdin`，通过子进程环境保留本次有效覆盖；真实后台重启验证通过。
2. **注册结果恢复**：GoTTY 在远程请求前私有保存 request ID 和 claim；响应丢失或最终凭据保存失败后恢复同一次注册。Hub 事务处理并发幂等，不重复创建实例。
3. **轮换、解绑与重试**：原注册请求不能恢复已轮换凭据或复活已解绑实例。失效请求返回后清理本机 pending 秘密，下一次明确点击可发起全新注册。
4. **登录竞态**：建立会话时再次要求账号存在且密码哈希仍为已验证值，不允许隐式建号或使用已重置的旧密码建立会话。
5. **管理员密码一致性**：密码变更串行化，配置私有原子写入，数据库提交失败尝试还原原配置；密码变化撤销旧会话。
6. **版本边界**：新 schema 升为 `0.2.0`，升级在替换前校验 staged binary 版本，拒绝低于当前版本的程序，防止安装旧邮箱版本。
7. **界面与统计**：修正注册页密码显示按钮的对齐；离线数量防止瞬时负值。截图等待弹窗入场动画结束，避免将正常过渡误判为模糊或遮挡。

## 数据与验证边界

- 按要求直接采用全新 schema，不编写旧数据库、配置、客户端或账号迁移。本轮测试始终使用隔离的新数据目录，没有修改现有部署数据。
- 仅凭用户名注册新实例给该账号是本方案明确允许的行为；这不建立该用户的浏览器会话，也不授予其他实例权限。
- 普通用户密码最少 12、最多 256 字节；admin 按最终要求只需非空且最多 256 字节。config 是明确要求保留的 admin 原始密码副本，普通用户密码不写入其中。
- ASR 使用本地确定性 fixture；未调用外部邮件或语音服务。移动端使用 Chromium 视口模拟，未宣称完成手机真机、公网 TLS 或容器生产验收。
- 前端构建仍有既有的 bundle 大小提示，GoTTY 依赖还会输出 Bootstrap/Sass 弃用提示；构建及测试通过。
- 现有 GitHub Actions 已适配新的初始化夹具和无邮件部署参数。实现与 review 阶段未触发远程工作流、发布新 Release、推送镜像或部署生产；因此没有将现存旧邮箱 Release 当作新版本做在线安装验证。降级拒绝有单测，binary 替换和实际重启已本地验证。
- 实现与 review 完成后，用户已授权提交并推送两个仓库；提交及远程工作流结果以 Git 历史和 GitHub Actions 记录为准。
