## 资源与使用边界

字体共 11 个 WOFF2 文件、1,302,620 字节；默认字体正体及斜体合计 164,576 字节。最终 Hub 前端约 2.8 MB、25 个文件，低于每代 32 MiB / 256 文件的资源预算。现有构建仍提示前端大分块及 Bootstrap Sass 弃用信息，不影响本轮构建与功能验证。

字体缓存由浏览器管理，清除站点数据、存储回收、隐私模式或更换访问 origin 后可能重新下载；这不等同于操作系统安装。Monaco/Menlo 不提供下载；中文及其他未覆盖字形使用系统回退字体。移动端使用真实 Chromium 的视口模拟，未宣称实体手机、所有输入法或 Safari/Firefox 均已实测。

新设置迁移涉及 schema 0003；升级和回滚需配套备份数据库。操作与维护说明见 [TERMINAL_SETTINGS.md](TERMINAL_SETTINGS.md)。本轮代码和验证产物已完成审阅，未切换现有服务。
