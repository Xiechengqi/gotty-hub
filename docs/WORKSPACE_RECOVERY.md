# 实例身份迁移与工作区恢复

GoTTY 的默认 Hub 身份按规范化监听地址、端口和基路径隔离，同一监听配置重启后保持原身份。状态文件位于 `~/.gotty/hub/<标识>.json`；若 `~/.gotty` 是旧配置文件，则使用 `~/.gotty-hub-bindings/<标识>.json`。显式 `--hub-state-file` 优先，可用于端口变化后仍保留同一身份。

同一状态文件只能由一个进程持有。锁文件在原子保存和进程退出后保留；锁由内核在进程结束时释放，不应删除 `.lock` 文件来绕过冲突。重复身份会在运行用户命令前报错。跨机器复制凭据仍会导致接替：Hub 记录 `device_connection_replaced` 审计，GoTTY 管理界面显示接替原因。

## 旧共享文件迁移

旧 `~/.gotty/hub.json` / `~/.gotty-hub.json` 没有记录监听信息，不能安全推断其属于哪个 GoTTY，因此不会自动套用到新路径。原文件保留，日志和 GoTTY 的 Hub 面板显示迁移提示。

1. 根据原 GoTTY 页面和 Hub 实例列表，核对旧文件中的 `instance_id` 对应哪个实例；不要把凭据内容贴到日志或工单。
2. 仅让该实例通过 `--hub-state-file <旧文件绝对路径>` 继续使用原身份；原实例授权及名称均保留。
3. 其他实例使用新的默认路径或各自独立的显式路径重新接入。旧共享文件只能保留最后一次写入的身份，无法恢复已经被覆盖的其他凭据。
4. 需要更换监听配置时，显式保留原状态文件路径；不要复制同一凭据同时运行。

迁移需要调整 GoTTY 启动配置；本次源码修复和隔离验证没有修改任何现有服务的配置或身份文件。

## 浏览器恢复行为

- 终端从浏览器可视区域顶部铺满全高，tab 行以默认 80% 不透明度（20% 透明度）的灰色背景覆盖其上。顶栏只有等宽实例标签、固定宽度的“＋”和设置；桌面高度 32px，移动端 44px。实例导航、更多箭头、页面刷新、固定和自动隐藏入口均已移除。
- 标签左键直接切换，按住左键从标签主体拖动排序；右键选中并打开操作菜单，菜单与顶栏共用背景颜色和透明度。触屏轻点切换，再次轻点当前标签打开菜单，长按拖动。Shift+F10 / 菜单键 / 向下方向键打开菜单。
- 标签菜单保留“刷新”、分屏相关操作、有权限的“重启”和“删除”，移除分割线、尺寸接管、左右移动、关闭标签及实例设置。实例详情侧栏和授权编辑、凭证轮换的前端代码一并移除。刷新保留该终端的 xterm 和滚动历史，仅重建连接，不重启远端 Shell，传输文件时先确认中断。重启保留所有者权限、能力检查和二次确认。
- “删除”调用原解绑接口，仅所有者可见并由后端再次校验，确认框显示实例名和断开 Hub 连接的影响。失败保留实例及分屏并允许重试；成功移除 tab 和失效分组，保留分屏另一侧终端；离线实例也可删除。
- 终端设置中的背景透明度范围为 0–100%（0 不透明、100 完全透明），共同影响 tab 行与标签操作菜单的背景；实时预览、取消还原，保存按账号同步；默认 20% 透明度，已有显式设置保留。修改透明度不重建连接、不重新加载字体、不改变终端行列数。
- 设置菜单顶部显示账号和中英切换；应用明暗切换已移除，终端配色继续保留。“＋”弹窗提供 Hub 地址、用户名及复制操作；兼容重新打开旧版本关闭过的实例。
- 首次迁移补齐当前账号有权访问的实例，后续新注册或新授权实例自动追加 tab，不抢走当前实例焦点；重复 SSE 和离线重连不重复打开，旧版本保存的关闭状态仍可恢复。离线保留身份，删除或撤权移除。
- 手机同样显示全部等宽 tab，名称随宽度省略，极窄标签显示序号，点击菜单可查看全名；不需要横拉。分屏组占两份宽度，组内均分。
- 历史回放期间不向当前 Shell 回送终端查询响应，并在 xterm 完成异步解析后恢复正常输入与响应。历史内容不交给 ZMODEM 探测器处理。

## 分屏工作区

- 从标签菜单选择“与右侧标签分屏”。仅与已打开标签顺序中的紧邻右侧实例配对；末尾标签、离线实例、已属于其他分组的右邻或宽度不足时显示不可用原因。
- 分屏组在标签栏中连续显示，并标明“左 / 右”。当前终端有选中边框与可访问名称，切换焦点时短暂提示名称，不再占用独立标题行；同名实例补充短 ID。
- 可保存多个独立分屏组；选择组内标签显示该组并切换当前终端，选择其他标签单独显示它，已有组不被替换。拖动任一组员整体移动分组；打开关闭过的实例不会插入组内。
- “交换左右”同时交换标签顺序和窗格位置，焦点跟随原实例。退出分屏保留已打开会话；删除或撤销组内实例权限则解除该组并显示可用成员。正常离线保留名称和位置，重连不会抢走另一侧焦点。
- 中间分隔条可拖动；左右方向键每次调整 2%，Shift + 方向键调整 10%，Home / End 到最小 / 最大宽度，Enter 或双击恢复等宽。每侧至少 360px，分隔条占 8px；工作区不足 728px 或手机布局时显示当前终端，保留所有分组和各自比例。
- `workspace.schemaVersion = 3` 统一保存 `opened`、导航 `order`、`active` 和 `groups`。交互立即写入账号缓存，再串行同步服务器。迁移旧布尔分屏和 v1/v2 工作区，确保组员相邻并补齐已有实例。旧固定、最大化和应用主题偏好退出读写。
- 注册仅生成 tab，首次查看或进入分屏时才挂载终端。已查看终端按稳定打开顺序保留，排序、分屏、交换、显示与隐藏都复用 xterm / WebSocket；主动刷新只重连传输；删除、离线或权限变化等生命周期动作按需重建或销毁连接。
- GoTTY 的 PTY 最小行列数、其他浏览器主导尺寸均不受布局改变。Hub 按服务端确认网格绘制，超出窗格时可在终端内部滚动，避免大字体和窄分屏下 Vim 错位。

当前菜单精简与删除流程的 review 见 [TAB_MENU_REVIEW.md](TAB_MENU_REVIEW.md)。标签交互与背景一致性见 [TAB_INTERACTION_REVIEW.md](TAB_INTERACTION_REVIEW.md)。透明顶栏基础方案及当时验证见 [OVERLAY_WORKSPACE_REVIEW.md](OVERLAY_WORKSPACE_REVIEW.md)。旧紧凑导航方案见 [COMPACT_WORKSPACE_REVIEW.md](COMPACT_WORKSPACE_REVIEW.md)。此前分屏方案保留于历史报告 [SPLIT_WORKSPACE_REVIEW.md](SPLIT_WORKSPACE_REVIEW.md)。

## 验证

构建两个项目的当前版本后，在允许启动测试进程的隔离主机运行：

```sh
# 在 frontend 中安装依赖和浏览器
npm ci
npx playwright-core install chromium

# 环境变量指向测试构建，脚本创建独立数据库、身份文件和回环端口
HUB_BINARY=/path/to/test/gotty-hub GOTTY_BINARY=/path/to/test/gotty npm run test:workspace
```

脚本验证 12 个真实 GoTTY 在线、重复身份拒绝、Vim 中文编辑及保存、刷新保留未保存的 Vim 会话、回放响应隔离、断线后刷新、其他终端不受影响、透明度预览/取消/保存/刷新恢复、偏好慢请求、账号隔离，独立 GoTTY 页面的 Vim 与回放，以及移动端等宽标签、旧关闭状态恢复和真实新注册实例的自动 tab。分屏回归还覆盖相邻分组、左键整组排序、焦点与输入隔离、交换、鼠标与键盘调宽、xterm / WebSocket 对象保持、未同步布局刷新恢复、320/375/414/768 像素响应式布局与分组恢复、离线重连和观察者权限撤销。菜单回归覆盖精简项目、删除权限、取消、失败重试、重复提交、分屏存活成员、离线及最后一个实例删除。所有子进程在结束时清理；结果和截图写入打印出的临时目录。

设置 `WORKSPACE_SUITE=overlay` 可单独运行透明顶栏与自动注册回归，`WORKSPACE_SUITE=split` 可单独运行分屏回归，`WORKSPACE_SUITE=menu` 可单独验证菜单及删除流程；测试仍使用独立账号、数据库、GoTTY 身份和临时端口。

可通过 `CHROMIUM_EXECUTABLE` 指定已有浏览器，通过 `TEST_ARTIFACTS` 指定临时报告父目录。Rust 测试二进制在另一台主机执行时，设置 `HUB_TEST_ASSETS` 指向与其嵌入资源相同的 `frontend/dist`。

Hub 的 `build-minifier.test.ts` 覆盖 xterm 局部枚举与 `||=` 的 ES2020 压缩回归；GoTTY 共享核心测试覆盖异步回放边界、旧回调和 UTF-8。构建设置保留标识符及空白压缩，关闭会生成未声明变量的语法压缩步骤。

共享尺寸控制、服务端历史快照和事件恢复见 [TERMINAL_DATAFLOW_REVIEW.md](TERMINAL_DATAFLOW_REVIEW.md)。设置 `WORKSPACE_SUITE=dataflow` 可运行专门的数据流回归。
