# 大文本粘贴进度实现与 review

## 实现结果

GoTTY 与 gotty-hub 共用 `terminal-core 0.5.0` 的输入队列和粘贴状态机。
外部剪贴板粘贴在网页中央显示非模态进度卡片，包含实例名、百分比、
UTF-8 字节数和“停止”。超过 8 KiB 或耗时达到 150 ms 才显示；成功约
1 秒后自动消失，错误与停止结果保留到手动关闭。卡片不抢焦点、不改变
终端尺寸，移动端跟随可视视口；分屏与切换焦点不会改变任务所属实例。

使用原生剪贴板事件捕获，保持 xterm 的换行规范及整次粘贴一对 bracketed
paste 标记。修复独立 GoTTY 对大 Uint8Array 使用参数展开造成的栈溢出。
普通按键按序排队，终端协议应答继续工作；取消、错误、刷新或断线丢弃
未发送输入及排队按键，避免排队的回车执行残缺内容。重复粘贴会提示等待。

## 协议与并发

新增输入 `5`、回执 `e`，上传使用的 `7` / `d` 不变。客户端最多保留
8 个未确认分块，每块最多 4 KiB；总量上限 64 MiB。回执记录真实 PTY
写入量，支持短写、失败、超时及取消；100% 只表示送入终端，不代表应用
处理完成或命令执行完成。没有相应能力的旧 GoTTY 显示“未经远端确认”
的发送进度，不冒充真实写入确认。

每个共享 PTY 同时允许一个粘贴任务，防止其他客户端按键或 API 命令混入。
GoTTY 的接收循环把粘贴交给有界 worker，不在会话锁内等待 PTY；取消、
心跳及其他实例的消息仍能处理。阻塞写入可取消；关闭标记清理有时限。
Hub 网关检查设备能力与写入权限，并有限等待发送队列，避免瞬时拥塞直接
断开连接。停止只影响剩余文本，已写入部分无法撤回，也不会自动补发。

## Review 中处理的边界

- 去除大数组参数展开；分块尊重 UTF-8 边界，统计不包含 base64 与控制标记。
- 拒绝乱序、大小不符和超限分块；错误、断线、权限变化清理任务。
- API 空闲检测在整个粘贴和清理期间保留用户占用，不因网络暂停而抢占 PTY。
- PTY 转为可取消写入后，调整尺寸使用安全的原始描述符接口，避免重新进入阻塞模式。
- 完成前处理关闭标记期间产生的终端查询回复，避免 Vim 等应用等待丢失的回复。
- 复制异步发送的二进制输入缓冲，防止调用方复用缓冲区改变排队内容。
- 外部粘贴解除移动快捷键修饰状态，并保留独立 GoTTY 的输入活动通知。
- 进度更新限频；使用现有按钮和进度样式，Hub 颜色使用语义 token；无聚焦陷阱。
