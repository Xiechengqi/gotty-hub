核验日期：2026-11-11。Hub 源码基线 `2925bce`，GoTTY 基线 `b836fcb`。本次只修改 Hub 前端、测试与文档，不涉及数据库迁移、服务端协议或 GoTTY 源码。

## 实现结论

| 范围 | 实现与审查结果 |
| --- | --- |
| 实例身份 | 参考浏览器分屏的持续身份提示，每侧固定显示名称、左右位置、状态和只读权限，当前侧有边框与文字标记；工具按钮包含目标实例名，同名实例补充短 ID |
| 固定配对 | `workspace` 明确记录左右实例、焦点侧和比例；标签及侧栏排序只改导航顺序，不再重新推导另一侧实例 |
| 选择与退出 | 可搜索并分别替换每侧；另一侧实例不可重复选择。点击已配对标签只切焦点，选择第三个实例只替换当前侧；交换让焦点跟随实例，退出保留已打开会话 |
| 关闭与断线 | 关闭配对中任一侧后显示另一侧，重开不自动分屏；正常离线保留标题与位置，重连回放不会抢走另一侧输入焦点 |
| 生命周期 | 所有终端在同一父容器下按打开顺序保留稳定 key，通过 Grid 列调整左右位置；排序、交换、调宽、替换及退出分屏均不重建已有 xterm 或 WebSocket |
| 焦点 | 显示与聚焦分离；显式请求有序号、完成确认及过期时间，等待弹窗退出后恢复输入，新的弹窗不会被旧请求抢焦点；异步复制不再主动聚焦来源终端 |
| 尺寸 | 指针拖动每帧合并，键盘支持方向键、Shift、Home / End 和 Enter；每侧最小 360px，分隔条 8px。服务端确认的 PTY 绘制尺寸与窗格可用尺寸分别处理 |
| 响应式 | 工作区不足 728px 或进入手机布局时显示单终端，保留桌面配对与比例；手机选择其他会话不会改写桌面配对，宽屏恢复原配对 |
| 保存与迁移 | 版本化偏好同步服务端，按账号同步写入本地缓存；尚未确认的本地选择优先恢复，旧请求不能确认新版本；迁移旧布尔分屏时保留原先实际左右位置 |
| 权限 | 恢复和实例列表更新均过滤无权访问的 ID；撤销一侧授权后收起为有权限的另一侧；观察者继续隐藏输入、上传、清屏与重启权限 |
| 组件与兼容 | 复用 BoardUI Button、Input、Modal 及其 ScrollFade，使用语义颜色和中英文文案；保留旧偏好字段供旧前端读取，不增加依赖 |

整体 review 修正了以下问题：

1. GoTTY 默认 PTY 最小为 60 列、20 行，24px 字体下的窄分屏可能只容纳约 36 列。原先直接 Fit 会使 Vim 在较小网格解释较大 PTY 输出，切换焦点重绘时错位。本次按服务端 `terminal-state` 确认尺寸绘制，独立上报窗格尺寸，超出内容可在终端内部滚动；确认尺寸不会回送成新的尺寸请求。
2. WebTTY 完成回放和复制完成时的聚焦逻辑可能抢走另一侧焦点；回放仅恢复当前已在该终端内的焦点，复制不异步抢焦点。
3. 原 Grid 间隙会额外占用分隔条两边各 1px，使最小宽度计算略有偏差；分屏布局统一由 8px 分隔条分隔，并实际测量 Home / End 边界。
4. 焦点回调通过 ref 更新，避免将父级新回调加入终端初始化依赖；布局动作不触发终端重新初始化。
5. 深色截图发现新增实例标题的次要文字颜色偏弱，改用主文字语义色；标题、左右标记与当前操作标记增加浅色 / 深色实际对比度检查，要求至少 4.5∶1。

## 使用边界

终端布局不能改变 GoTTY 的 PTY 最小尺寸或其他浏览器的尺寸主导策略；网格超过窗格时通过内部滚动查看完整内容。浏览器回归使用真实 Chromium，手机尺寸为视口模拟，未覆盖实体手机、Safari 或 Firefox。
