## Review 中修正的问题

1. 标签自动居中可能使正在点击或拖动的标签移位，滚动还会关闭 React Aria 菜单。改成仅在需要时滚动到可见区域；菜单、拖拽和标签内焦点期间不主动滚动。测试也等待程序滚动与排序回弹动画完成后再计算鼠标坐标。
2. 取消固定后，按钮焦点会阻止导航隐藏。固定按钮完成操作后显式恢复当前终端焦点，同时保留菜单和键盘操作期间的可见性。
3. 多个受控菜单关闭回调可能覆盖新打开的菜单。关闭只作用于对应实例与入口；右邻目标在打开时固定，顺序变化时禁用原目标。
4. Escape 取消拖拽可能同时传给 Vim。拖拽开始时把焦点移至排序单元；取消和完成后恢复终端。窗口失焦或指针取消通过 dnd-kit 的取消路径释放手势，不提交排序；模拟取消事件发到 document，不发到终端。
5. 旧 v1 待同步缓存没有包含导航顺序。恢复时合并原 `instanceOrder` 并保存 v2 快照，避免丢失原排序或无法确认同步。
6. 深色导航的次要文字对比度不足。标签和新菜单采用主文字语义色，浏览器检查浅色 / 深色标签对比度至少 4.5∶1。分屏身份提示短暂显示，避免一直覆盖终端首行。
7. 短视口菜单支持内部滚动与 BoardUI ScrollFade；抽屉复用已有 Drawer / ModalBody 的滚动处理。已移除旧会话切换组件和旧分屏实例选择组件。
