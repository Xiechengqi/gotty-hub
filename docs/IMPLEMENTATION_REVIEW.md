# 实施结果与整体 Review

日期：2026-11-09。范围：GoTTY 与 GoTTY Hub 两仓库，本地实现与验证；未生产部署、发真实邮件或推送外部制品。

## 实现结果

P0–P5 的主要功能已落地：终端专用 Go/Rust WSS、共享 WebTTY 核心、Cookie/CSRF/OTP/Argon2id、角色与活跃撤销、注册/凭据落盘/轮换/解绑、单一设备状态来源、真实多标签工作台。P6 文件/可选 ASR/快捷输入及 viewport 已实现，P7 包含故障恢复测试、压测脚本、Docker/Compose、CI 和运维说明。原规划中的真机和生产环境验收不能以本地结果代替。

最终终端是 Hub 原生 xterm + GoTTY 共享核心；不穿透整个 GoTTY 管理页。浏览器布局沿用确认过的原型：无首页/分组/收藏、账号在侧栏顶部、顶部齿轮、居中添加弹窗、状态图标、独立折叠、最大化及桌面双分屏。演示数据仅通过显式 `?preview=1` 访问。

实现与原计划的主要取舍见 ADR：临时非对称设备证明改为 HTTPS 上的256位随机 claim；固定版本 tarball 分发共享 WebTTY/语音源码；状态与文件/viewport 由 Go/React 适配实现，未将所有 UI 与状态逻辑强行搬进 TypeScript 核心；SSE 首版用每秒授权快照；OpenAPI 是路径目录，详细请求与鉴权契约在 API.md。没有宣称生成完整强类型 SDK。

## Review 发现及修复

| 问题 | 修复及验证 |
|---|---|
| 关闭标签后 SSE 重新打开 | 仅首次快照恢复标签；真实浏览器验证关闭及刷新恢复 |
| 撤销后连接可能继续使用旧授权 | 每输入及500ms校验会话/版本；角色、退出、改密、解绑测试 |
| 设备轮换先提交导致落盘失败后锁死 | 两阶段凭据摘要/落盘ACK，重连可提交 pending；恢复集成测试 |
| 重复设备连接误用解绑清空身份 | superseded 与 revoked 分离；替换连接停止抢占 |
| 查看期间输出离开后误报绿色 | 真实输出路径记录 unseenOutput，查看清除；Go 状态时序测试 |
| 离线打开标签仍显示灰点 | 状态渲染统一离线 SVG；灰点只表示在线空闲 |
| 授权角色误由排序推断 | 使用服务端实际 owner/operator/observer |
| 手机隐藏分屏仍上报尺寸 | 分屏有效状态按视口与已打开数量限制；隐藏终端不发送尺寸 |
| 恢复时活动标签无效 | 过滤获授权实例，并回落到已打开标签 |
| 共享核心修改不触发嵌入资源构建 | GoTTY Makefile 包含共享包源文件依赖；重新 webpack |
| 旧密码验证与改密并发建立新会话 | 会话插入原子比较已验证密码哈希；密码重置与撤销用事务；过期哈希回归测试 |
| 无主密码的管理身份不明确 | 本机0600 .admin令牌，拒绝分享身份注册 |
| 密码计算资源无并发界限 | 独立阻塞worker与4并发信号量 |
| 设备凭据/数据库/开发邮件权限 | 文件0600、目录0700；日志不记录秘密或PTY负载 |
| 原型文案/账号进入生产 | 默认真实模式；账号取服务端邮箱；API错误双语化 |
| 非所有者不能查看允许的实例详情 | 所有角色可查看名称/在线/角色，只有所有者呈现授权、轮换、解绑控件 |
| Caddy示例与宿主机部署不匹配 | 上游改为127.0.0.1:8088，与Compose发布回环端口一致 |
| 全部会话退出缺少入口 | 账号面板增加有效会话数量与退出所有设备 |
| Origin配置允许含路径 | 启动严格解析HTTP(S) origin，拒绝用户信息/路径/query/fragment |

## 已运行验证

- Go：`go test ./...`、`go test -race ./server` 通过。
- GoTTY JS：类型检查、8文件71测试通过；webpack生产构建成功。Bootstrap/Sass 上游弃用和包体积提示仍存在。
- Rust：格式、Clippy `-D warnings`、4单元/协议测试通过。
- Hub：TypeScript与生产构建通过，15项Playwright原型交互回归通过；包含320/375/414/768/1440宽度、双语、折叠、最大化、弹窗与状态来源隔离。
- 真实集成：邮件绑定/OTP、xterm到bash真实往返、rz上传/sz下载内容一致、取消、关闭标签；观察者伪造输入拒绝、授权隔离/撤销、票据重放、CSRF/Origin、匿名访问、密码登录/修改/重置及旧会话失效、ASR专用流和观察者拒绝。
- 故障恢复：设备凭据轮换写盘、活动流关闭；GoTTY进程停止和重启；Hub停止和重启；保存身份自动重连；解绑关闭流并清除本机身份。
- 共享包：`scripts/check-core.py /path/to/gotty` 校验 Hub vendor tarball 与 GoTTY 来源一致，npm lock 固定 integrity。CI 可独立构建Hub并测试，不依赖相邻工作区。

压测：50个真实GoTTY进程、100条鉴权终端WS、10个实例持续输出，1800秒，收到1,224,212,698字节，意外断连0，Hub峰值RSS22,804KiB（约22.3MiB），结束前CPU累计平均约27.6%。本轮压测使用debug构建、共享宿主机环境，长测启动后仍有review修复，测试inode摘要与环境在 [load-environment.json](load-environment.json)。随后最终服务构建同档位补测60秒，收到71,854,808字节，意外断连0，峰值RSS22,176KiB。

原始数据：[30分钟报告](gotty-hub-load-report.json)、[最终构建补测](gotty-hub-final-load-report.json)。可复现命令见README。此记录验证持续连接与汇总吞吐，没有测量p99交互延迟，也不代表生产容量承诺。慢消费者/恶意连接/目标环境磁盘满需要另行压力验收；有界队列和发送超时不等于这些故障全部已实测。

## 环境边界与发布前验收

1. iPhone Safari / Android Chrome 真机不可用：仅 Chromium 模拟视口，未声称实机中文输入、软键盘及后台恢复已验收。
2. Resend 真实投递、真实语音识别使用的上游服务未调用：测试使用私有开发邮箱与本地确定性 ASR fixture；需目标配置验证。
3. 当前 Docker daemon 不可用：提供 Dockerfile/Compose，未完成容器运行、amd64/arm64 镜像及公网TLS反向代理的实际验收，也未发布镜像。
4. SQLite备份/完整性检查/恢复已加入隔离集成测试；目标环境磁盘满与实际备份介质演练需运维执行。单节点无HA，代理地址聚合限流的边界见运维文档。
5. 上述环境验收未完成前，不能把原计划P6/P7的所有发布门槛标为通过。本轮代码与本地集成结果不等于生产可用性认证。
