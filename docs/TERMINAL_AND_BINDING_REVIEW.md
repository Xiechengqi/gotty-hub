# GoTTY 终端一致性与接入面板 Review

日期：2026-11-09。此文更新原实施规划的终端显示与接入交互部分。

## 行为

Hub 继续直接访问 GoTTY 的共享 PTY，不嵌入管理网页。两端共享 terminal-core 0.2.0 的显示默认值、字体列表、主题名称与 xterm 偏好转换。默认 Nord、Source Code Pro、14px、500 行回滚；GoTTY 在回放输出前发送完整显示偏好、内置主题目录、ASR 热键和延迟等可公开配置。浏览器本地设置按实例保存，切换标签和双分屏互不覆盖；不同站点的 localStorage 不跨 origin 自动同步。

Hub 的终端背景随所选终端主题变化，独立于工作台明暗模式；移除旧的 13px 固定字号、终端内边距和桌面常驻快捷键条。右侧恢复 GoTTY 的 28×28、4px 圆角、半透明背景按钮，以及连接人数；提供显示设置、清屏、原生上传和拖放、重启及 Hub 实例设置。Unicode 11、图片、WebGL、选择复制及 OSC 52 写剪贴板也与 GoTTY 对齐。

GoTTY 的 Hub 配置入口改为按钮旁展开的非模态面板，与其他浮层互斥，支持再次点击、外部点击和 Escape 收起。新增可选显示名字；留空继续自动生成。成功后显示绿色“接入 Hub 地址 成功”，输入框只读，提供编辑、重新接入和断开。断开持久保存暂停状态并立即关闭隧道，Hub 中实例显示离线；重新接入保留原实例 ID、凭据和授权。编辑同一 Hub 下的名字通过设备身份验证更新原实例。

注册和改名受数据库唯一索引保护：同一 owner 下名称去除首尾空白、ASCII 大小写不敏感；名称最多 80 个 Unicode 字符，不允许控制字符。并发同名注册只有一个成功，另一请求返回 409 `instance_name_exists`，GoTTY 显示明确错误。不同 owner 可使用同名实例；同一设备的幂等重试不会撞名。

修改 Hub 地址或用户名时，新注册请求与 claim 在私有 `.pending` 文件暂存，失败保留原活动绑定，成功保存新凭据后才切换隧道。旧 Hub 中的原记录保持离线，需删除时在原 Hub 解绑。

## 权限和边界

| 操作 | 所有者 | 操作者 | 观察者 |
|---|---|---|---|
| 显示设置、连接人数、终端输出 | 可用 | 可用 | 可用 |
| 输入、清屏、原生上传、ZMODEM、ASR | 取决于 GoTTY 能力 | 取决于 GoTTY 能力 | 禁止 |
| GoTTY 服务重启、GoTTY 分享管理 | 可用，且依赖远端配置 | 禁止 | 禁止 |
| Hub 绑定、授权管理 | 沿用 Hub 所有者规则 | 只读信息 | 只读信息 |

远端管理仅增加 `restart/shares/share_create/share_stop/share_restart/share_delete` 命名操作，不接收任意 HTTP 请求或执行命令。Hub 在当前会话、票据和授权版本内复核所有者权限，GoTTY 从已认证 open 帧保存角色并再次校验。每条控制请求不超过 16KiB、每个设备同时一个操作、60 秒客户端超时；连接关闭释放挂起请求。重启沿用 GoTTY 原服务重启实现，不以重启 PTY 冒充。分享记录经过原有密码摘要脱敏。

显示配置只序列化白名单，不包含 GoTTY 访问密码、Hub 设备凭据、ASR 地址或分享服务密钥。改名接口只接受对应设备 Bearer 凭据和实例 ID，Cookie 不授予设备改名权限。

## 验证边界

使用 Go race 单测、Go vet、Go/Hub 前端单测、TypeScript 检查、Rust 单测/Clippy、前端生产构建及二进制编译验证。新增覆盖真实 WebTTY 消息分派到 React 适配器、主题与字体、只读按钮、控制消息关联和断线清理、接入面板只读/编辑/绿色成功状态、重名错误、原身份重连、私有暂存与回滚、并发唯一注册和设备改名鉴权。

遵守本次用户限制：不进行本地部署验证，不运行浏览器或截图，不执行本地集成/负载脚本；DOM 测试在 jsdom 中运行，API 测试使用内存路由/数据库或请求替身。

旧 GoTTY Connector 不声明 controls 能力时，Hub 隐藏服务管理按钮，显示采用统一默认值。完整主题目录、远程偏好、改名及管理功能需要两端都更新。
