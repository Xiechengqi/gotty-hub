# 分屏窗格临时放大与整体 review

## 最终行为

- 点击分屏窗格右上角的状态圆点 / 终端名标签，选中并居中放大该终端；标签图标和无障碍名称随放大 / 还原切换。
- 点击边框外右上方的浅色圆形按钮、再次点击标签或点击背景遮罩还原。按钮视觉直径 32px、触控区域 44px，保留与边框的 8px 间距；浅色背景及深色叉号不随终端主题反转。
- 遮罩统一使用 8px 背景模糊和轻度终端主题色。背景终端继续接收输出并按原语义报告可见性，标签栏、其他窗格及分页暂时不可交互，横滑切换暂停。遮罩点击不穿透。
- Esc 不关闭放大层，也不被该层消费；Vim、终端和内层弹窗保留原有按键行为。上传 / 分享等弹窗使用既有层级和关闭规则。
- 放大使用真实可用尺寸，保留同一个 DOM、xterm 和 WebSocket；不复制、重建或通过缩放图片模拟终端。底层网格轨道保持原有布局。
- 只在当前页面内存保存放大状态。刷新、切换账号、当前成员移出 / 删除或分屏组消失，以及降级至小屏布局时退出放大。短暂离线不主动退出。

## 实现与 review

扩展 BoardUI 的弹层基础能力，增加始终挂载的 `InPlaceModal`。复用 React Aria 的 overlay 栈与焦点作用域，但禁用该层的键盘关闭行为；还原不依赖另一个 Portal 中的终端副本。

终端主动聚焦时仅排除其自身的原位弹层，仍避让上传、分享、确认框等子弹窗。粘贴任务仍保存在独立 store 中；进度 Portal 注册为所属放大层的子焦点作用域，因此放大 / 还原不停止任务，键盘仍可操作停止和关闭按钮。

尺寸基于应用现有 `visualViewport` 高度、顶部偏移及安全区域。顶部至少预留外侧按钮和间距，避免短屏、平板横屏及软键盘遮挡按钮。只对遮罩淡入和按钮颜色使用短动画，不逐帧改变终端几何尺寸；减少动态效果时关闭动画。

Review 检查了背景 `inert` 的撤销、Scope 与事件清理、还原焦点、布局变更后的临时状态失效、默认 / 悬停 / 聚焦 / 按下 / 禁用样式、关闭按钮对比度，以及浮层在当前窗口外侧时的点击区域。修正按下样式被悬停样式覆盖的优先级，并为不支持 `color-mix()` 的浏览器补充遮罩颜色回退。关闭按钮实测背景 RGB 247/247/247，叉号 RGB 10/10/10。没有发现遗留阻断问题。

## 实际边界

同一 GoTTY 实例仍共用一套 PTY 网格。放大带来的真实容量变化继续经过既有策略协商，不强制接管；如果改变共享网格，其他客户端也可能看到程序重新排版。历史保留预算及 VT 快照能力不变。

WebKit 验证使用 Linux 上的真实引擎，软键盘高度及偏移由受控 `visualViewport` 模拟；没有在实体 iPad Safari 上验收。放大背景不阻止终端持续输出，模糊合成的实际开销仍取决于设备 GPU 与同时输出量。
